# EnergyMonitor

IoT Energy Monitoring System based on ESP8266, PZEM-004T, PHP, MySQL and Chart.js.

## Structure
- `energy-monitor/dashboard` — web dashboard
- `energy-monitor/api` — data and alarm APIs
- `energy-monitor/config` — database configuration
- `energy-monitor/esp8266_energy` — ESP8266/PZEM firmware
- `energy-monitor/alarm` — alarm interface

## Baseline
Imported from the `energy-monitor.zip` project supplied for this development session.
